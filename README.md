## 88 键钢琴 · 乐谱与演奏挑战

路径：`apps/central-c-ball/index.html`

### 实时识别

- 完整显示钢琴 A0 到 C8 的 88 个琴键，包括 52 个白键和 36 个黑键；
- 使用 Web Audio API 获取频谱，结合多谐波证据估计多个同时出现的音符；
- 使用最低输入音量门槛、频谱对比度和基频强度联合筛选，避免极弱噪声直接触发琴键；
- 连续两帧确认同一音高后才点亮琴键，减少瞬态杂音和偶发频谱峰值造成的误识别；
- 汇总多个低音的预期泛音贡献，过滤由多个音符泛音叠加产生的虚假高音，同时保留真实八度、五度等和弦音；
- 跟踪单个音符的起音能量变化，改善同音重复敲击的识别；
- 同时识别多个候选音符，并点亮对应白键或黑键；
- 显示当前主音频率、识别音符列表和同时识别数量；
- 检测输入削波并给出降低音源音量或麦克风增益的提示。

### 乐曲创作与导入

- 导入 MuseScore 4 的 `.mscz` 压缩乐谱和 `.mscx` XML 乐谱；
- 同时支持导入 MusicXML（`.musicxml` / `.xml`）及 GDT 乐曲 JSON；
- 解析音符、和弦、休止符、附点、常见连音、延音线、延长记号（Fermata）、拍号和速度记号；
- 展开 MuseScore 开始/结束反复、反复次数、常见第一/第二结尾，以及 D.C./D.S. 跳转，按实际演奏顺序生成挑战乐谱；
- 读取乐谱中途的速度变化，并按每个音符所在位置的 BPM 计算真实播放时间；
- 按 MuseScore `timeStretch` 和 MusicXML 延长记号形状读取保持倍率，延长对应音符/休止符，并推迟后续演奏时间；
- 在 88 键键盘上点选音符，多选琴键可组成和弦；
- 设置 BPM、拍号和音符时值，添加音符或休止符；
- 使用 Web Audio 合成音色试听乐曲；
- 自动保存最近编辑内容到当前浏览器，并可下载 `.gdtmusic.json`；
- 导出 MusicXML，保留速度变化和延长记号，并将已展开的反复播放顺序导出为线性乐曲，可在 MuseScore 4 中继续打开和编辑。

### 演奏挑战

- 乐谱中的每个音符变成对应琴键位置的下落条形，条形不再显示音符文字；
- 条形的垂直长度按音符实际持续时间计算，包含附点、常见连音、延音线、延长记号和速度变化；
- 按乐谱反复和跳转后的真实播放顺序安排下落时间；
- 条形到达琴键时，通过麦克风检测演奏音高；
- 匹配成功后，对应条形消失；未及时匹配会计为未命中；
- 和弦会同时产生多个下落条形，分别判断每个音符；
- 显示命中数、未命中数和准确率。

### 数据与识别边界

- 乐谱文件在浏览器本机解析；麦克风音频仅在本机处理，不上传录音；
- 麦克风需要 HTTPS 或 localhost 权限；
- MSCZ 导入重点是音高、节奏、反复和速度数据，不完整还原谱面排版、歌词、复杂装饰记号及所有高级记谱细节；
- 当前挑战采用单路麦克风频谱多音高估计，不等同于 MIDI 级别的完整复调转录。谐波重合的音程、强混响、鼓点/失真音色和复杂编曲仍可能造成漏检或误检；提高灵敏度后，嘈杂环境下也可能增加误识别；
- 精确的复杂和弦挑战建议使用 MIDI 或数字音频接口输入。

## 开发和部署

代码位于 `main`，Pages 工作流在 `.github/workflows/pages.yml`。提交到 `main` 后会触发静态站点部署，无需构建命令。

本地调试：

```bash
python3 -m http.server 8000
```

打开 <http://localhost:8000/apps/central-c-ball/>。
